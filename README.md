# Personal Portfolio

This is my personal portfolio website, created to share a little about who I am, my journey in technology and the experiences that are helping me grow as a Computer Science student.

The portfolio is also a space where I can experiment with web development, design and interactive experiences while continuing to learn.

## About the Project

I created this portfolio from scratch as a personal project.

My goal was to build something that represents not only my technical journey, but also my curiosity, creativity and interest in exploring different areas of technology.

The website includes sections about:

- My journey in Computer Science
- My interests in technology and creativity
- My first experiences beyond the classroom
- Techstars Startup Weekend
- Ways to connect with me

## Technologies

- HTML
- CSS
- JavaScript
- GSAP
- ScrollTrigger

## What I Practiced

While developing this project, I practiced:

- Structuring a website with HTML
- Creating layouts and visual styles with CSS
- Using JavaScript for interactions
- Creating scroll-based animations
- Working with GSAP and ScrollTrigger
- Improving the user experience through small visual details

## My Journey

I'm still at the beginning of my journey in Computer Science, so this portfolio will continue evolving as I learn new technologies, build new projects and gain new experiences.

For me, this project is not just a portfolio — it's also a way to document that progress.
